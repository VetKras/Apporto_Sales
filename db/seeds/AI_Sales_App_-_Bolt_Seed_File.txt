AI Sales App - Bolt Seed File
Single build handoff for Bolt

==================================================
SYSTEM PURPOSE
==================================================

Build Apporto Sales: a web-based sales intelligence, pricing, product, and competitive analysis app for the Apporto AI Suite.

V1 sellable products:
- CoTutor
- PowerGrader
- TrustEd
- ExamSpace

Single user-facing assistant:
- Portia

Portia helps sales, sales engineering, sales leadership, marketing, customer success, and product-facing teams:
- answer product questions
- configure deals
- generate quotes
- create customer-facing proposals
- create internal deal strategy
- compare competitors
- extract feedback from uploads/transcripts/notes
- propose source-data updates under authority rules

Portia is assistant only in V1. Do not seed Portia as a sellable product.

==================================================

Use:
- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui

==================================================
PORTIA ASSISTANT RULES
==================================================

Portia never invents pricing math.

Portia must use deterministic quote engine outputs and database records:
- pricing_config_versions
- pricing_models
- deal_inputs
- quote_lines
- calculated quote totals

Portia labels serious claims as:
- confirmed source-of-truth
- user-provided claim
- inferred recommendation
- data gap
- internal-only

Customer-facing outputs:
- no COGS
- no margin
- no internal approval logic
- no hidden TCO assumptions
- no internal doubts

Internal outputs:
- include source trace
- include config version
- include quote calculation version
- include margin/cost assumptions when available
- include approval level
- include confidence and data gaps

Competitive rules:
- never fabricate competitor claims
- mark weak evidence as [data gap]
- separate competitor claim, customer-observed signal, Apporto confirmed capability, and Portia inference

==================================================
AUTHORITY MODEL
==================================================

Level 1: Low / new or unknown employee
- Cannot overwrite system truth.
- If data conflicts with Apporto truth, block immediately.
- Return exact conflict and supervisor escalation message.

Level 2: Standard sales/product user
- Creates proposed updates.
- Cannot directly overwrite system truth.

Level 3: Manager / domain owner
- Performs deeper analysis.
- Creates strong proposed updates with evidence and confidence.

Level 4: Executive / company leadership
- Highest-trust source.
- Still no silent overwrites.
- Conflicting data requires deferential analysis, confirmation prompt, then audited override if confirmed.

No silent overwrites.

==================================================
PRICING ENGINE REQUIREMENTS
==================================================

Implement pricing engine before AI proposal generation.

AI must consume calculated quote objects. AI must not calculate totals itself.

All pricing values:
- stored in pricing_config_versions and pricing_models
- configurable
- versioned
- source-traced
- reproducible on quote_lines

Active pricing config seed:

Config version:
- version_name: v1-active-defaults
- notes: Active V1 configurable defaults from current Apporto Sales planning and PO app config.
- is_active: true

CoTutor active configurable defaults:
- Departmental/Premium: 20 per student/year
- Campus/Standard: 15 per student/year
- Platform/Entry: 10 per student/year

Important:
- Old CoTutor 80/65/50 workbook values are historical/reference context.
- Do not use 80/65/50 as active V1 defaults unless a newer active pricing_config_version explicitly reactivates them.

PowerGrader initial defaults:
- per student: 15 per student/year
- per faculty: 120 per faculty/year
- per submission: 4 per submission

TrustEd initial defaults:
- standalone: 50 per student/year
- bundle add-on: 40 per student/year

ExamSpace initial defaults:
- medium: 11 per seat-day
- large: 16 per seat-day
- gpu: 23 per seat-day
- platform fee: 1200/year for new customers
- setup fee: 2500 one-time for new customers

Quote formula:
- line.list_price = quantity * unit_price
- line.discount_amount = allocated discount for that line
- line.net_price = list_price - discount_amount
- line.total_cost = quantity * unit_cost, if unit_cost exists
- list_total = sum(line.list_price)
- discount_amount = list_total * (discount_percent / 100)
- final_total = list_total - discount_amount
- cost_total = sum(line.total_cost)
- gross_margin_percent = final_total > 0 ? ((final_total - cost_total) / final_total) * 100 : null
- per_student_price = student_count > 0 ? final_total / student_count : null

Bundle suggestion defaults:
- 2 products: 10%
- 3 products: 15%
- 4 products: 20%
- Do not auto-apply bundle discount unless user clicks Apply.

Approval matrix:
- 0-5%: Sales
- >5-10%: Manager
- >10-15%: VP
- >15%: CFO/Executive

Course assumptions:
- estimated_assignments_per_year = course_sections * 6
- estimated_exam_days_per_year = course_sections * 2

TCO planning:
- low_tco = final_total / 0.70
- high_tco = final_total / 0.60
- TCO assumptions are internal-only unless explicitly approved for customer-facing output.
